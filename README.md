# YuriChess

This is a UCI-compatible chess engine using the same algorithm as <https://princess.software/yuri/>. It should work with any chess GUI that knows how to speak UCI. It is not very good at chess.

Run it in the usual Python way: make a venv, `pip install -r requirements.txt`, and then run `main.py.` As a convenience, once you have the venv set up, you can run `yurichess.sh` (on bash-type systems) or `yurichess.bat` on Windows-type systems. 

You can play against it on Lichess at <https://lichess.org/@/PrincessYuribot> and <https://lichess.org/@/StraightBot>!
